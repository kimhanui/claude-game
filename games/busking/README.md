# 버스킹

3인칭 1인 플레이. 해 질 녘 광장 가운데에서 기타를 연주하면 들리는 범위의 행인이 하나둘 멈춰 서서 듣는다.

## 조작
- 키 하나 = 기타 한 음 (`e.code` 기준이라 한/영 무관, 키를 누르고 있어도 반복 연주 안 함)
  - `Q ~ P` 높은 도~미 (C5~E6), `A ~ ;` 가운데 도~미 (C4~E5), `Z ~ /` 낮은 도~미 (C3~E4)
- 터치 기기: 하단 패드 10개 (가운데 도~높은 미)
- 화면 끌기: 시점 회전, 휠·핀치: 확대, ↺: 시점 초기화, `Esc`·`?`: 조작법

## 동작 규칙 (`game.js` 상단 `CFG` 로 조정)
- 마지막 음 이후 `playHold`(2.2초)까지 "연주 중"
- 열기(heat): 음마다 +0.03, 연주 중 서서히, 쉬면 빠르게 식음
- 들리는 거리 = `hearBase + hearGain × 열기` (8m → 최대 18m). 범위 안 행인은 걸으면서 고개를 돌려 쳐다봄
- `stopGap` 간격마다 범위 안 행인 한 명을 정면 반원 자리(11곳)로 불러 세움 → 한두 명씩 늘어남
- 8음 이상 연주 후 멈추면 듣던 사람들이 박수, `quietBeforeLeave`(3.5초) 넘게 조용하면 한 명씩 떠남
- 연주 중이어도 `patience`(40~90초) 지나면 떠날 수 있고, 떠난 사람은 `reStopCooldown` 동안 다시 멈추지 않음

## 구조
- 기타 소리: Web Audio Karplus–Strong 합성 (음별 버퍼 캐시), 박수: 필터 노이즈
- 사람 모델: 박스·실린더 조합 (`makePerson`), 행인 상태 `walk → approach → listen → walk`
- 테스트 훅: `window.__busk` (`step(dt)`, `paused`, `noteOn`, `npcs`)
